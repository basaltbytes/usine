# @usine/config

Config file machinery for [usine](https://github.com/basaltbytes/usine), an agent-agnostic software factory: parse, validate, and surgically rewrite the instance repo's files — `usine.yaml` (version, registry, settings), loop files (`loops/*.md`), and agent files (`agents/*.md`). Markdown-with-frontmatter parsing, strict schema validation, and a comment-preserving YAML-AST writer so UI edits never clobber hand-authored formatting.

Part of usine. This block is not implemented yet — its 0.0.x releases reserve the seam while the engine grows. Everything here is 0.x: APIs change without notice.
