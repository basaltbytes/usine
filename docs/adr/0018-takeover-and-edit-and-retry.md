# Takeover and edit-and-retry: session-addressed interventions, held children, sticky amendments

Takeover is conversing inside a live session. The attempt channel's inbound envelopes (steer, interrupt, operator message) gain a **session target** — the Pi parent by default, or a harness child addressed by its id from the normalized event stream — and operator messages join the target session as user turns via the subagents extension's streaming-input bridge (which every harness backend already supports). The first operator message to a child places a **hold**: an idle held child defers returning its result to the awaiting parent until an explicit release; the parent's spawn call just keeps waiting, so parent orchestration is never cut out. Holds are per-child and concurrent; the parent has no hold semantics — it returns to no one. **Edit-and-retry** amends a failed run before its next attempt: the editable unit is the **task text** (the interpolated loop-body result — the context preamble stays engine-owned, the persona always comes from the agent), plus an agent swap from the roster. Amendments are **sticky** — they rewrite the run's effective context, and every later attempt, capped auto-retries included, runs it until amended again. Both record without new entities: operator messages, holds, and releases are attributed envelope types persisted in the transcript — never Events — and the Attempt row gains an **operator-intervened** flag; each attempt records the effective task text and agent it actually ran (ADR 0005's observe-by-record). The runaway guard's wall-clock pauses while a hold is open, exactly as for an open ask — operator presence is supervision — while the token ceiling stays armed.

## Considered Options

- **Detach-and-own takeover** — the parent's spawn call resolves with a taken-over marker and the operator drives the child to completion. Rejected: cuts the parent out and forks the step-result path.
- **Child steer only** — a one-shot text at the child's next tool boundary, no conversation. Rejected: multi-round exchange is the point of attaching — the same reasoning that chose ask-and-park over ask-and-end ([ADR 0017](./0017-away-intervention-github-native-asks.md)).
- **Claim/release mode** — explicit bracketing envelopes forming an exclusive recorded span. Rejected as heaviest; the implicit hold gets the completion-deferral without a channel state machine. **No hold at all** (child returns whenever idle, operator races completion) rejected as unusable.
- **Interventions as Events** — one ledger for all operator acts. Rejected: the Event ledger would fill with chat turns; Events stay run-opening/consumed facts (triggers, approvals, ask answers), in-flight interaction is the transcript's job.
- **Edit scope alternatives** — steer-text-only (collapses into ADR 0002's existing retry steering), the whole composed blob (fights the three-part prompt assembly and the persona-rides-into-child path), all three parts independently (three surfaces to explain and record), snapshot refresh (the attempt would no longer read the Event it answers). All rejected for task text + agent.
- **One-shot amendments** — rejected: a typed-infra-error auto-retry would silently revert the operator's fix.

## Consequences

- Additive to [ADR 0006](./0006-executor-contract-run-host-attempt-channel.md): inbound envelopes carry a target session id; operator-message and release types join the channel (the versioned envelopes absorb this, transport-agnostic). A parent parked on an ask (ADR 0017) doesn't block child addressing — a live child is takeable regardless of parent state.
- Revises [ADR 0002](./0002-run-model-event-run-step-attempt.md): retry's "optional steering text" grows into the run's sticky effective context (task text + agent); Attempt rows gain the operator-intervened flag. No new state-machine edges — edit-and-retry rides exactly the existing failed → running transitions, runaway restarts included.
- Revises [ADR 0013](./0013-cost-accounting-native-meters-guardrails.md) the way ADR 0017 did: the runaway wall-clock pause extends from open asks to open holds; the token ceiling stays armed during takeover.
- [ADR 0008](./0008-web-ui-projects-kanban-spine.md)'s run drawer: the parent transcript and each child's session events become chat surfaces with a per-child release control; failed runs get the edit-and-retry form (task-text editor + roster agent picker). UI-only — a GitHub 👍 restart (ADR 0017) never carries edits.
- An agent swap on retry re-derives persona and brain spec from the swapped roster agent; usage lands in that agent's pool per child, as ADR 0013 already meters.
- **Takeover**, **Hold**, and **Edit-and-retry** enter the glossary.
