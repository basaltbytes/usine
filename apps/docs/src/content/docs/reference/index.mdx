## CLI

- [CLI](/reference/cli/): the `usine` commands, their flags, and environment variables.

## Configuration

- [`usine config`](/reference/configuration/config/): edit configuration, import or export a folder, and list revisions.

- [`usine.yaml`](/reference/configuration/usine-yaml/): the YAML import and export format for instance settings, projects, and workers.
- [Loop files](/reference/configuration/loop-files/): the export files in `projects/<project>/loops/`, one loop each.
- [Agent files](/reference/configuration/agent-files/): the files in `agents/`, one agent each.
- [Expressions](/reference/configuration/expressions/): the CEL that loop conditions and prompt templates use.

## HTTP API

The [operator HTTP API](/reference/operator-api/) documents instance reads, configuration, run actions, and sign-in. Download its [OpenAPI document](/openapi.json) or fetch `/api/openapi.json` from a running instance.
