Choose the task you want to complete. For a first agent pull request, start with the [quickstart](/get-started/quickstart/).

## Run usine

[Run usine locally](/guides/run-usine-locally/) to install the CLI, start an instance, and open its web UI. [Host usine on a Linux server](/guides/host-usine-on-linux/) for an always-on setup with systemd, HTTPS, and managed upgrades, or [host usine on a Mac](/guides/host-usine-on-macos/) with launchd.

The [Run usine guides](/guides/run-usine/) also cover backups, restores, upgrades, and moving an instance.

## Workers

[Add and maintain workers](/guides/workers/) on your machine, SSH hosts, Boat, [boxd](/guides/add-a-boxd-worker/), Hetzner, or Cloudflare. Configure gateways and check worker capabilities.

## Loops and agents

[Define loops and agents](/guides/loops-and-agents/) to select work and choose how it runs. Connect review and fix loops, edit configuration, and pause admissions.

## Work with runs

[Approve and follow runs](/guides/work-with-runs/), message agents, answer questions, and retry or repeat work. Export results and read instance statistics.

## Access

[Sign in and manage access](/guides/access/) for members and API clients.
