---
title: Run completed work again
description: Open a new run for a succeeded or canceled run’s saved item state.
---

Run a loop again on the same item content without changing GitHub labels.

## Prerequisites

A succeeded or canceled run, project operator access or a higher role, and no open run of the same loop on the item.

## Procedure

1. Open the run drawer, run page, or task row menu.
2. Select **Run again** to keep the task and agent, or **Edit and run again** to change them before selecting **Save and run again**.
3. Inspect the new run and approve it if the current loop requires approval.

## Check the result

A new run links to the original and records the actor and time. It follows the current loop’s approval condition and cycle budget. Run again works on a paused loop; the original outcome stays unchanged.
