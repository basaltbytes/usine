usine runs coding agents on GitHub issues and pull requests in the repositories you register. You define loops that select the work, then approve and follow runs in a web UI.

<Aside type="caution" title="Alpha software">
  The configuration format, the CLI, and the `@usine/*` package APIs can change in any release. Back up the instance folder and read the release notes before you upgrade.
</Aside>

Use usine when you want to repeat a repository task, such as implementing a labeled issue or fixing review findings, with instructions you control. An instance runs on your machine or server; agents can use Claude Code, Codex, or Pi.

The quickstart uses a scratch repository, the local worker, one agent, and one loop. You create a small README issue, approve its run, and review the pull request the agent opens.

<LinkButton href="/get-started/quickstart/">Start the quickstart</LinkButton>

To start an instance without the first-pull-request exercise, [run usine locally](/guides/run-usine-locally/) or [host usine on a Linux server](/guides/host-usine-on-linux/). The [Run usine guides](/guides/run-usine/) cover access, upgrades, backups, and moves.

Read [Concepts](/get-started/concepts/) for the terms in the UI. After your first pull request, [write a loop](/guides/write-a-loop/) for your own work or [operate runs](/guides/follow-a-run/) to follow and steer an attempt.

Give coding agents [llms.txt](/llms.txt) for a page index and links to the full and abridged documentation.
