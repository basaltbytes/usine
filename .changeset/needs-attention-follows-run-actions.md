Needs attention follows a run action sent from any page. While the drawer, a board card, a stalled row, or the entry itself approves or cancels a waiting run, the entry's buttons are disabled and name the action in progress, such as "Approving…", and the entry leaves as soon as the action succeeds, before the overview refreshes. An approval refused because the run had already moved on, such as one approved in the drawer first, shows no error on the entry, which leaves with the refresh; the drawer and the run page still say why usine refused it.
