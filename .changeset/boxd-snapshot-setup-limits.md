`infra/boxd/build-snapshot.mjs` limits the setup on the temporary machine. When the setup runs longer than 20 minutes, or the minutes that `--setup-timeout` sets, or prints nothing for 5 minutes, the script stops it, logs the egress allowlist that boxd reports for the machine, and fails with the setup's last 20 output lines. apt gives up on a connection after 30 seconds without data, and `apt-get update` and the Tailscale installer run once more if they fail or don't finish in time. The setup prints a line for each failed run, and when a run doesn't finish in time, the script logs the egress allowlist that boxd reports. On an interrupt, in any phase of the build, the script logs `Interrupted; deleting the temporary machine` and deletes the machine at once, or as soon as boxd returns the machine it is creating. The deletion and each egress read go through a new client; on an `https://` endpoint, each opens a new connection instead of reusing one that may have gone idle. After it lifts the machine's egress allowlist, the script waits five seconds, fails unless boxd still reports the allowlist lifted, and logs the second read. Each log line starts with the time.
