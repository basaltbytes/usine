Web UI messages that named `usine.yaml` now name the **Configuration** page where admins change the setting. A missing worker, a paused worker, a worker that is no longer configured, and an empty **Worker utilization** block point to **Configuration > Workers**. A missing repository points to **Configuration > Repositories**. Undeclared loop labels and a repository's **Labels usine creates** section point to **Configuration > Labels**.
