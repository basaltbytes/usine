A task chip in a conversation, a run transcript, or an agent question shows the issue or pull request that the text names. In a sentence, it cuts a long title to keep the sentence readable and shows the title in a tooltip. In a table cell, it shows the mark, the number, and the status mark. The status is never cut. A Markdown table that is wider than its column scrolls sideways.
