The web UI's Tasks list shows usine's work per Task: only the Tasks with at least one Run, finished ones included, with no Done toggle and no `?done=1`. Each row shows the status, the Loops that ran with their last Run's state and the Run count, the last Run, the pull request with its state, such as `#425 merged`, and the task's time, tokens, and cost, with the tokens per billing pool on hover. The status is `Running` with the Loop, `Waiting for approval`, the stall reason, `Needs attention`, `Done`, or the last Run's outcome, such as `Failed`. A queued run shows the stall reason about that run. Tasks in flight come first, by when their Run opened, then every other Task by when its last Run closed, so a run canceled before any attempt counts from the cancel; GitHub's update time is no longer a sort key. The heading counts `2 in flight, 1 needs attention, 2 done`, a line under it adds up `9 runs, 6 h 12 min, 4.8M tokens, $14.20 estimate`, and a project where no Task has a Run says `No runs yet`.
