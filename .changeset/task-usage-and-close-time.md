`RunView` in `@usine/orchestrator/operator` carries `closedAt`, when the run last closed, null while it is open. The desk's last outcomes use it. `BoardTaskView` carries `usage`, a `TaskUsageView` with what the task's runs used: the ended attempts' wall time, when each attempt at work started, the attempts closed before end times were recorded, the tokens, the tokens and dollars per billing pool summed over the runs' sessions, and the priced pools' dollars. Each pool is a `TaskPoolUsageView` whose `cost` adds up the priced sessions and whose `unpriced` says a session in a pool with a dollar rate has no price yet, so a running Claude session before its first result leaves the dollars already spent in the cost, which is then a lower bound. The overview reads each run on the board's items through `RunUsageReader`, which keeps ended attempts' reports, and `RunUsageReader.read` accepts a run summary as well as a snapshot. A token report adds no projection revision, so each read of a kept overview reads the attempts at work again and adds up again the cards whose runs used more. Code that constructs `RunView` or `BoardTaskView` adds the fields.
